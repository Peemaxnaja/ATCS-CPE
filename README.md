## 🛠️ LLM Data Pipeline & Task Assignment

เพื่อไม่ให้เกิดการทับไลน์และ Git Conflict จนบ้านแตก สาธุชนคนขยันโปรดมาลงชื่อจับจองขั้นตอนของตัวเอง ณ บัดนี้:

| ขั้นตอน | ชื่อ Task | คำอธิบายแบบเข้าใจง่าย | คนแบก (ใส่ชื่อตรงนี้) | Status |
| :---: | :--- | :--- | :--- | :---: |
| **1** | **Collection** | ไปขุด, ไปดูด, ไปสอยข้อมูลจากทุกแหล่งมารวมกันไว้ที่เดียว | `@เพื่อนคนที่ๅ` | ⏳ Pending |
| **2** | **Cleaning** | ลบแท็ก HTML, โฆษณาเว็บพนัน, Header/Footer และข้อความซ้ำออกให้เกลี้ยง | `@เพื่อนคนที่2` | ⏳ Pending |
| **3** | **Normalization** | ปรับฟอนต์ จัดช่องว่าง แปลง Unicode อย่าให้ภาษาต่างดาวหลุดมาเด็ดขาด | `@เพื่อนคนที่3` | ⏳ Pending |
| **4** | **Chunking** | หั่นข้อความเป็นชิ้นๆ (Chunks) ขนาดพอดีคำ ไม่สั้นไปไม่ยาวไป | `@เพื่อนคนที่4` | ⏳ Pending |
| **5** | **Metadata** | แปะป้ายบอกประวัติ (ชื่อเอกสาร, ผู้เขียน, วันที่, แหล่งที่มา) เพิ่มความไฮโซ | `@เพื่อนคนที่5` | ⏳ Pending |
| **6** | **Embedding** | แปลงร่างข้อความมนุษย์ให้กลายเป็นเวกเตอร์ตัวเลข (Math จงสถิตอยู่กับท่าน) | `@เพื่อนคนที่6` | ⏳ Pending |
| **7** | **Vector Database** | เอาเวกเตอร์ไปยัดลงฐานข้อมูลเพื่อการค้นคืน (Retrieval) แบบจ๊าบๆ | `@เพื่อนคนที่7` | ⏳ Pending |
| **8** | **LLM / Retrieval** | ดึงข้อมูลมาร้อยเรียงแล้วส่งให้บอสตอมตอบคำถามอย่างมีคุณภาพสูงสุด! | `@หัวหน้าห้อง` | ⏳ Pending |
